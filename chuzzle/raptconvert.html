RaptConvert

  • query string / checksum blob is converted to utf-8, or base 64-decoded if already encoded
  • checksum uses a simple XOR cipher - each byte is XORd with "youcanonlytrustalibertarian", and if any data byte matches the key byte it's left unchanged
  • result is base64-encoded






these could have url encoding - %2B for "+" and %3D for "=". if a copy gives %%2B / %%3D, then that's wrong and the tool will normalize that. raw base 64 only is also fine XOR is from String::Encrypt in the lib sibling (skip XOR when data byte equals key byte)
